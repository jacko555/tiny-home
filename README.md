# Tiny Home Design Tool

Interactive React and Three.js concept tool for a 6m x 3m raised tiny-home frame.

## What It Shows

- 3D frame, foundation, roof, exterior, interior, and fixing layers
- 2D plan/elevation views
- 190x45 H3 external floor frame and doubled crossmember brace lines
- 140x45 H3 remaining joists, wall frame, roof frame, and deck framing
- Concrete pier grid and floor/foundation concept checks
- Bunnings-seeded AUD materials estimate

## Local Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Engineering Note

This is a concept visualization and takeoff tool only. Footings, spans, bracing, tie-downs, uplift, soil bearing, waterproofing, local approvals, and manufacturer fixing schedules still require qualified engineering and code review.
